ENGLISH SPELLING MASTER — iPhone PWA starter

Files:
- index.html: app
- manifest.webmanifest: install metadata
- sw.js: offline cache
- icon-192.png / icon-512.png: app icons

IMPORTANT:
This is a Progressive Web App starter, not an APK and not an App Store package.
To install on iPhone, these files must be hosted on an HTTPS website.
Then open the HTTPS address in Safari > Share > Add to Home Screen.
The app's service worker caches the app for offline use after its first successful load.

For a simple hosting route, publish this folder using GitHub Pages or another HTTPS static host.
